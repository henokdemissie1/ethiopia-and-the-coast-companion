# Changelog

## First Edition — v1.0

Companion baseline dated 27 October 2026. This is the first public companion release for a prepublication book baseline; it does not declare the manuscript final.

- Preserves the five original World Bank numerical input vintages and the separate later verification snapshots.
- Provides fifteen machine-readable tables, unrounded teaching rows and an 89-entry source directory.
- Makes calculation reproduction independent of access to the full manuscript.
- Adds source-query provenance, including recovered documented original GDP API URLs whose responses match the baseline data.
- Separates current supplied figures from regenerated numerical equivalents and their underlying plot data.
- Excludes the full manuscript, private review notes, stale internal package manifests and superseded redline figures.
- Records component-specific source credits and reuse terms separately from rights in the book and referenced publications.

No numerical observation or selected scenario input was changed while preparing this public baseline. Later changes to data vintages, assumptions, code or illustrations should receive a new version and an explicit change record.
