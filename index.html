Start with the evidence

Download and extract the ZIP. Read README.md first. Tables are provided as CSV files and figures as PNG images, so these materials can be explored without running the scripts.

  • Dated World Bank observations with original units and source metadata.
  • Shipment, investment and regional production examples with explicit assumptions.
  • A figure registry, data dictionary, source queries and component-specific reuse notices.

Reproduce the analysis

The numerical calculations run offline with Python 3.10 or later and its standard library.

python reproduce_core_models.py --tables-only
python reproduce_supplemental.py
python export_tables.py

Figure regeneration also needs Pillow. The README explains the command and the difference between supplied original figures and regenerated equivalents.

What the numbers mean

Historical observations and chosen scenarios serve different purposes. The teaching scenarios are not measurements of current Assab conditions, forecasts of investment returns or estimates of a causal maritime-access effect. The central hub example fails its transport-savings-only test; positive production illustrations do not remove that result.
